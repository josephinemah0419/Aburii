# ABURII Hero v2 assets

These production assets were generated specifically for the ABURII homepage hero. They do not reuse uploaded references, previous hero generations, or external stock photography.

- `wagyu-whole.png`: isolated whole Wagyu object
- `wagyu-slices.png`: four matching isolated Wagyu slices used as independent animated layers
- `yakiniku-grill.png`: compact Japanese charcoal grill object

Smoke, flame, sparks, and ember glow are rendered as separate lightweight CSS layers.

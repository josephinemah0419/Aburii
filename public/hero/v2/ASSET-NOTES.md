# ABURII Hero v2 assets

These production assets were generated specifically for the ABURII homepage hero. They do not reuse uploaded references, previous hero generations, or external stock photography.

- `wagyu-whole.png`: isolated whole Wagyu object
- `yakiniku-grill.png`: compact Japanese charcoal grill object

The slicing animation reuses `wagyu-whole.png` as its only meat source. Four animated clipping masks progressively divide the same visual object; no alternate sliced-Wagyu image is loaded or crossfaded.

Smoke, flame, sparks, cutting highlights, and ember glow are rendered as separate lightweight CSS layers.
